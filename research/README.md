# Research summaries

These Markdown documents consolidate the relevant context from the owner's URP
records. They are editorial summaries, not replacements for the historical code
or claims of newly reproduced findings. Understanding them requires no access
to the original external folder.

- [Final study](final-study.md): problem, method, settings, and reported findings.
- [Development notes](development-notes.md): proposal, dataset generation, VAE
  reconstruction, RL prototype, and shift toward interpolation.
- [Workshop abstract summary](abstract-summary.md): a short account of the final
  project and its stated conclusions.
- [Source catalogue](SOURCES.md): source titles, locations within the original
  records, and SHA-256 identifiers for the reviewed documents.

The original external records included reports, notes, literature, and program
paperwork. This archive incorporates the relevant research context as readable
summaries; it does not import the external document collection.
