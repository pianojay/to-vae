# Historical supporting material

This directory preserves supporting material already present in the original
repository; it is separate from the project's main research contributions.

- [code](code/): PPO examples, a PyTorch/MNIST VAE notebook, and original solver
  references under the historical `_depreicated` spelling, including a ZIP.
- [demos](demos/): original example figures and `top88.docx`.
- [mnist_data](mnist_data/): reference-example data, including raw downloads and
  processed snapshots. This is not topology training data.

Original credits and files are preserved. No additional literature collection or
administrative files were imported from the external URP folder. The project's
own reports and notes are represented by [Markdown summaries](../research/README.md)
with a [source catalogue](../research/SOURCES.md).
